# 📚 Bookstore Web Application

## 🚀 Overview
This is a full-stack bookstore application where users can browse, add, edit, and manage books.

## 🛠️ Tech Stack
- Frontend: React.js, Redux
- Backend: Django REST Framework
- Database: SQLite
- Authentication: JWT

## ✨ Features
- User Registration & Login
- Add / Edit / Delete Books
- View Books List
- Secure API Integration
- Responsive UI

## 📦 Installation

### Backend
cd backend
pip install -r requirements.txt
python manage.py runserver

### Frontend
cd frontend
npm install
npm start

## 🔗 API Endpoints
- GET /books/
- POST /books/
- PUT /books/:id
- DELETE /books/:id
